행동중재 도우미
특수교사·담임교사가 학생의 문제행동을 정의 → 기록 → 시각화 → 분석 → 행동중재계획서 작성까지 한 곳에서 할 수 있는 웹 앱입니다.
설치나 서버 없이 브라우저에서 바로 동작하며, 모든 자료는 사용하는 기기의 브라우저(localStorage)에만 저장됩니다.
주요 기능
메뉴	기능
🎯 표적행동	행동명, 조작적 정의, 포함/제외 예시, 측정 방법, 5점 강도 척도, 중재 시작일 설정. 자주 쓰는 행동 예시(소리 지르기, 자리 이탈, 공격·자해 행동 등) 템플릿 제공
✏️ 기록	빈도: +1 버튼으로 즉시 기록, 지난 기록 일괄 입력 · 지속시간: 스톱워치(새로고침해도 유지) 또는 직접 입력 · 강도: 1~5점 척도 버튼, 방금 기록에 강도 추가 · ABC 분석지: 장소/활동, 선행사건·후속결과 체크리스트 + 서술, 지속시간·강도, 추정 기능
📅 달력	월별 달력에 빈도/총 지속시간/평균 강도/ABC 건수를 색 농도로 표시, 날짜를 눌러 기록 확인·추가·수정
📈 그래프	일별 빈도(추세선 포함)·지속시간·강도 그래프에 기초선/중재 구분선 표시, 시간대별·요일별 발생, ABC 기반 기능 비율, 선행사건/후속결과 빈도
📝 중재계획	기간을 지정해 자료를 분석하고 행동중재계획서(BIP) 초안 자동 생성 → 화면에서 직접 수정 → 인쇄/PDF, Word(.doc), HTML로 저장
⚙️ 설정	학생 관리, JSON 백업/복원, 기록 CSV 내보내기(엑셀용), 예시 데이터
계획서 자동 분석 내용
관찰일 수, 일평균·최대 빈도, 평균·최장 지속시간, 평균·최고 강도, 추세(선형 회귀)
기초선 vs 중재 단계 비교: 평균 변화율, 비중복 자료 비율(PND)
ABC 기록의 선행사건·후속결과·관찰자 판단을 가중 합산하여 행동 기능(관심/회피/획득/감각) 추정 및 신뢰도 표시
추정 기능에 맞춘 예방(선행사건) 전략, 대체행동 교수, 후속결과 전략, 위기행동 관리 계획, 목표(단기·장기), 평가 계획, 역할 분담
AI 챗봇으로 계획서 다듬기 (API 키·비용 없음)
앱은 AI API를 직접 호출하지 않습니다. 중재계획 → 📋 자료 복사를 누르면 분석 결과와 ABC 서술 기록이 정리된 글이 복사되고,
사용자는 이를 본인의 Gemini·ChatGPT 계정(배포자가 미리 만든 젬/GPT 또는 일반 대화창)에 붙여넣어 계획서를 받습니다.
앱에는 처음부터 개인정보를 넣지 않으므로(아래 참고) 넘어가는 자료에도 실명이 없습니다.
배포자는 docs/챗봇-지침.md의 지침으로 젬/GPT를 만들고, 링크를 `js/config.js`에 넣어 배포하면 됩니다.
개인정보 최소화
학생은 가명(예: 학생A, 별님)으로만 등록합니다. 생년월일·학교명·연락처 등의 입력란은 없습니다.
실명처럼 보이는 이름(흔한 성씨 + 2자)을 입력하면 가명 사용을 다시 안내합니다.
ABC 서술란에도 실명 대신 '친구1', '담임'처럼 적도록 안내합니다.
> 자동 생성된 계획서는 **초안**입니다. 학생지원팀 협의를 통해 반드시 검토·수정하세요.
실행 방법
`index.html` 파일을 브라우저로 열면 됩니다. 또는 로컬 서버로 실행:
```bash
npm start        # http://localhost:8080
```
처음에는 예시 데이터로 둘러보기를 눌러 6주(기초선 3주 + 중재 3주) 분량의 예시 자료로 기능을 확인해 볼 수 있습니다.
개발
```
index.html          화면 뼈대
css/style.css       스타일 (모바일 하단 탭 지원, 계획서 인쇄 스타일)
js/analysis.js      자료 분석 (일별 집계, 추세, 단계 비교, 기능 추정)
js/plan.js          행동중재계획서 생성
js/export.js        AI 챗봇에 붙여넣을 자료 텍스트 생성
js/config.js        배포자 설정 (미리 만든 챗봇 링크)
docs/챗봇-지침.md    젬/GPT 만들기 안내와 챗봇 지침
js/store.js         localStorage 저장소, 예시 데이터, 행동 템플릿
js/app.js           화면/이벤트 처리
js/vendor/          Chart.js 4.4.1 (오프라인 동작을 위해 포함)
tests/              분석·계획서 단위 테스트
```
```bash
npm test
```

CSV 기록 가져오기
설정 화면의 기록 CSV 추가에서 CSV를 선택하고, 미리보기에서 추가 건수와 중복·오류 행을 확인한 뒤 확정합니다. 기존 기록은 삭제하지 않습니다. CSV 가져오기는 현재 브라우저의 로컬 저장소에 기록을 추가하며, 여러 기기 간 동기화는 포함하지 않습니다.
